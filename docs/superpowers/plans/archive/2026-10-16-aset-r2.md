# Aset R2 — E4-1..6

> Ikuti [peta worktree](2026-10-16-peta-worktree-baren.md), SRS EI-04..06, FR-ADM-15..17/24/26, NFR-SEC-03/05, NFR-PRF-03, C-04/06/07. Mulai checkbox hanya bila `Dep` di breakdown `Done`; status/bukti/progress/log di §4–5. Baca panduan Next.js 16 untuk route/image loader.

**Tujuan:** Browser admin mengunggah langsung ke R2 dengan URL sementara, menghapus aset aman, gambar publik optimal. **File milik jalur:** `src/lib/r2.ts`, `src/app/api/assets/**` (stub saat ini merespons sukses palsu dan wajib diganti), komponen uploader baru di `src/components/admin/`, loader R2 di `src/lib/`. `wrangler.jsonc` binding sudah E0-3; bila perlu CORS atau izin bucket, dokumentasikan konfigurasi tanpa rahasia. Koordinasikan tipe record/ownership dengan Data+API sebelum delete.

## Langkah

- [x] **E4-1** (Dep E0-3): audit helper `src/lib/r2.ts` dan binding `BAREN_ASSETS`; tetapkan metode presign yang **benar-benar kompatibel** dengan akses R2 browser dan Workers, key acak, expiry ≤600 detik, origin publik permanen terpisah dari signed URL. Bila binding saja tak dapat menandatangani URL untuk direct upload, gunakan API S3 R2 dengan kredensial secret dan signing kompatibel Web Crypto; jangan proxy file lewat Worker. Uji upload dari browser/curl ke R2 tanpa Worker sebagai jalur data.
- [x] **E4-3** (Dep E4-1): schema tipe/MIME/size server: JPG/PNG/WebP, SVG **hanya logo/ikon** ≤5 MB, MP4 ≤50 MB; jangan percaya ekstensi/nama file saja, verifikasi metadata yang tersedia pada tahap commit/objek; reject tipe lain/ukuran berlebih. Samakan aturan dengan validasi klien (hanya UX).
- [x] **E4-4** (Dep E4-1): loader `next/image` untuk domain publik R2, fallback/sizing aman, lazy di bawah fold; verifikasi URL final bukan URL signed kedaluwarsa, koordinasikan dengan E9-2.
- [x] **E4-2** (Dep E4-1, E2-4): ganti stub `PUT /api/assets` dengan penerbit presigned URL: Zod request (purpose, MIME, bytes), cek admin 401/403 sebelum sign, response `{ key, uploadUrl, publicUrl }`, expiry ≤10 menit, CORS browser dan metadata size/type. Uji anonim, Google-only, invalid type/size, expired URL; `DELETE` stub juga harus ditutup dari akses anonim segera saat rute diganti. **Done 2026-10-16** — guard `requireAdminResponse`, key server-side, expiry fixed 600, `bytes` = klaim klien (verifikasi aktual di integrasi berikut), `Content-Type` ikut ditandatangani, log tanpa secret/signature; expiry-600 endpoint vs expiry-1-dtk unit terpisah; 400 validasi vs 500 konfigurasi/signing; `DELETE` 401/403/501; `assets-auth.ts` dihapus; lint/tsc/format/build + unit presign/skema + anon-401 preview lolos.
- [x] **E4-5** (Dep E4-1, E2-4, E3-5): endpoint delete admin dengan konfirmasi di UI pemanggil (E8-10), validasi key milik bucket dan referensi DB; koordinasikan urutan record/objek dan kegagalan parsial supaya tidak meninggalkan record menunjuk objek hilang. **Done 2026-10-16** — guard 401/403 + Zod key 400 + `keyFromPublicUrl` ketat (origin persis, tolak query/hash/kredensial/traversal) + HEAD idempoten (`deleted:false` hilang, `deleted:true` ada, ulang idempoten) + `deleteAssetObject` murni unit 4/4; urutan DB→R2 + outbox = acceptance E8-6; R2-nyata S3-DELETE 204 terpisah; `--remote` tak mungkin (wrangler no-auth sandbox), bukti `deleted:true` via seed R2 lokal + endpoint.
- [x] **E4-6** (Dep E4-2, E0-2): uploader drag/drop dengan fallback pilih file, progress, validasi klien, preview, status error dan keyboard; PUT langsung ke `uploadUrl` dari browser, simpan metadata via API setelah sukses, jangan pernah POST file ke Worker. **Done 2026-10-16** — presign just-in-time per file + XHR progress/AbortController + tombol Unggah eksplisit/Coba Lagi/Simpan Lagi/Batal + status terunggah→menyimpan→tersimpan/gagal-simpan + `onUploaded` opsional (`void|Promise`, tanpa callback = "Terunggah ke R2"); retry triple-atomik (presign ulang, 3 key baru terbukti); gagal-ambigu = tombol manual bukan retry-buta; unit core 8/8; Playwright 8/9 (upload-nyata-R2 terbukti di E4-2 via curl; egress browser sandbox diblokir).
