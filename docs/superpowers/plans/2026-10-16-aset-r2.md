# Aset R2 — E4-1..6

> Ikuti [peta worktree](2026-10-16-peta-worktree-baren.md), SRS EI-04..06, FR-ADM-15..17/24/26, NFR-SEC-03/05, NFR-PRF-03, C-04/06/07. Mulai checkbox hanya bila `Dep` di breakdown `Done`; status/bukti/progress/log di §4–5. Baca panduan Next.js 16 untuk route/image loader.

**Tujuan:** Browser admin mengunggah langsung ke R2 dengan URL sementara, menghapus aset aman, gambar publik optimal. **File milik jalur:** `src/lib/r2.ts`, `src/app/api/assets/**` (stub saat ini merespons sukses palsu dan wajib diganti), komponen uploader baru di `src/components/admin/`, loader R2 di `src/lib/`. `wrangler.jsonc` binding sudah E0-3; bila perlu CORS atau izin bucket, dokumentasikan konfigurasi tanpa rahasia. Koordinasikan tipe record/ownership dengan Data+API sebelum delete.

## Langkah

- [x] **E4-1** (Dep E0-3): audit helper `src/lib/r2.ts` dan binding `BAREN_ASSETS`; tetapkan metode presign yang **benar-benar kompatibel** dengan akses R2 browser dan Workers, key acak, expiry ≤600 detik, origin publik permanen terpisah dari signed URL. Bila binding saja tak dapat menandatangani URL untuk direct upload, gunakan API S3 R2 dengan kredensial secret dan signing kompatibel Web Crypto; jangan proxy file lewat Worker. Uji upload dari browser/curl ke R2 tanpa Worker sebagai jalur data.
- [ ] **E4-3** (Dep E4-1): schema tipe/MIME/size server: JPG/PNG/WebP, SVG **hanya logo/ikon** ≤5 MB, MP4 ≤50 MB; jangan percaya ekstensi/nama file saja, verifikasi metadata yang tersedia pada tahap commit/objek; reject tipe lain/ukuran berlebih. Samakan aturan dengan validasi klien (hanya UX).
- [ ] **E4-4** (Dep E4-1): loader `next/image` untuk domain publik R2, fallback/sizing aman, lazy di bawah fold; verifikasi URL final bukan URL signed kedaluwarsa, koordinasikan dengan E9-2.
- [ ] **E4-2** (Dep E4-1, E2-4): ganti stub `PUT /api/assets` dengan penerbit presigned URL: Zod request (purpose, MIME, bytes), cek admin 401/403 sebelum sign, response `{ key, uploadUrl, publicUrl }`, expiry ≤10 menit, CORS browser dan metadata size/type. Uji anonim, Google-only, invalid type/size, expired URL; `DELETE` stub juga harus ditutup dari akses anonim segera saat rute diganti.
- [ ] **E4-5** (Dep E4-1, E2-4, E3-5): endpoint delete admin dengan konfirmasi di UI pemanggil (E8-10), validasi key milik bucket dan referensi DB; koordinasikan urutan record/objek dan kegagalan parsial supaya tidak meninggalkan record menunjuk objek hilang. Uji key asing, 401/403, objek hilang, kegagalan DB/R2, dan penghapusan sukses.
- [ ] **E4-6** (Dep E4-2, E0-2): uploader drag/drop dengan fallback pilih file, progress, validasi klien, preview, status error dan keyboard; PUT langsung ke `uploadUrl` dari browser, simpan metadata via API setelah sukses, jangan pernah POST file ke Worker. Uji pembatalan/gagal unggah dan URL yang kedaluwarsa.

**Verifikasi:** `pnpm lint && pnpm exec tsc --noEmit && pnpm format:check && pnpm build`; `pnpm preview` + upload/delete nyata ke bucket uji, cek network browser bahwa body file menuju host R2 dan Worker hanya menerima metadata, bukan byte file. Jangan tandai integrasi sukses bila kredensial R2/CORS uji tidak tersedia; catat blocker.
